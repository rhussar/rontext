**Project name:** Rontext

**Description:**

Rontext is a self-hosted personal CRM I built to replace a paid networking app. It keeps one record per person and layers on what LinkedIn, Gmail, Calendar and Messages already know about them, then turns that into a daily Home feed: who to reply to, whose headline just changed, whose birthday is coming up, who I've gone quiet on. Outreach drafts can be AI-written in my own voice, but nothing is ever sent automatically.

Under the hood it's a Next.js 16 app on Vercel with Neon Postgres, a nightly job runner, a Chrome extension that captures LinkedIn profiles as I browse, a Mac agent for iMessage counts, and an MCP server so an AI agent can work the network with the same guardrails. The public demo runs the real code on a database of fictional people; the source is open under AGPL so anyone can run their own copy with their own data.
